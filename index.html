Daily Operational Discipline

SOD & EOD Daily Routine

Engineering companies run on reliable cadence. At Iconic Hub, we practice structured morning planning and nighttime proof submissions.

Morning SOD 9:00 AM – 10:00 AM

Start-of-Day (SOD) Commitment

Every morning between 9:00 AM and 10:00 AM, submit your daily plan: 2 to 5 targeted tasks, estimated completion hours, and any blockers needing mentor help.

> SOD (9:15 AM): Implement JWT auth middleware + unit tests
Flexible Execution 4 Hours Core Focus

Focused Build & Code Reviews

Spend 4 dedicated hours building features, pushing code to GitHub branches, reviewing squad pull requests, and brainstorming with peers.

> git push origin feature/api-endpoints
Night EOD 10:00 PM – 12:00 AM

End-of-Day (EOD) Proof

Between 10:00 PM and midnight (12:00 AM), submit your EOD report detailing task completion percentages and verifiable links (GitHub PRs, live URLs, or Figma boards).

> EOD (10:45 PM): PR #14 merged • 100% completed with proof
